# SIRA self-learning RAG

## What this pack lets workers do

A collection of nouns and verbs for offline corpus-discriminative Seed Pack enrichment (`SIRA`),
cross-domain structural problem-isomorphism indexing (`RA-RFT`), execution-report reflection into
edge shim rules (`MR-Search`), and bounded `DGM-H` self-improvement proposals gated by an
independent verifier. Inspired by Meta `SIRA` (June 2026), `RA-RFT`, `MR-Search` and `HyperAgents /
DGM-H` (March 2026), workers collapse multi-round exploratory catalog search into one single-shot
retrieval action and retrieve structurally analogous packs across distinct surface domains.

## Nouns

| Noun (task object) | What it holds |
| --- | --- |
| Guardrails | Forbid self-verification on `DGM-H` proposals (`proposer != verifier`); keep compiled edge shims deterministic under `2.0 ms`; never mutate holdout or evaluator controls |
| `spec.sira-rartf-dgmh` | Core structural isomorphism frames, `12`-frame analogy space, `60`-query benchmark contract and `< 2.0 ms` shim budget |
| `rules.isomorphism-and-shim-gates` | Corpus-discriminative TF-IDF specificity, I/O signature extraction, concept-bridge expansions and `DGM-H` two-step verification checks |
| `tool.sira-rag` | Tested standard-library Python package in [code/](code/README.md), pinned by path, file count and digest |
| `template.sira-analogy-receipt` | JSON Schema for baseline vs `SIRA + RA-RFT` top-1 pack, compiled shim count and verification status |
| Worked example | Four-pack pharmacy separation-of-duties query (`example.sira-analogy-bundle`) and recomputed receipt (`example.sira-analogy-receipt`) |

## Verbs

| Verb (task) | Who | What happens |
| --- | --- | --- |
| `enrich-corpus-and-analogy-frames` | agent, no model | Extract discriminative vocabulary, I/O signatures, predictive query expansions and `12` structural frames |
| `compile-sub2ms-shim-rules` | agent, no model | Reflect over Task execution reports to emit zero-model routing and pruning shim rules |
| `verify-dgmh-proposal-independently` | agent, no model | Enforce `proposer != verifier`, zero holdout regressions and `surface_only` scope before owner review |

## How to use it

Run `make check` in [code/](code/README.md) to compile with warnings treated as errors and run
all unit tests including the `60`-query benchmark across all `79` Seed Packs and worked-example recomputation.

## Limits

- Quarantined, unverified proposal until reviewed: this pack is not installed, imported, admitted or
  activated, and no worker has claimed or run these tasks through Tessera.
- Offline enrichment, shim compilation and `DGM-H` verification run deterministically (`mode: local_verified`) and never promote changes without owner review.
- Structural isomorphism retrieval surfaces candidate packs; accountable workers and people still verify domain fit before acting.
