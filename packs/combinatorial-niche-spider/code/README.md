Standard-library Python package for combinatorial niche-cell minting across 48 domains (including Blender/3D, Godot, Three.js/WebGPU, OCR and document intelligence, privacy tools, GIS/maps, robotics and nonprofit operations), page-cursor coverage ledgers, persistent breadth-first spider frontiers (`depth 1..8`), purposeful refresh (`movers` and `404 gone`), bounded multi-wave follow-up verb proposals and 8-axis `0-100` evaluation with query-family yield benchmarks.

Run checks offline:

```sh
make check
```
