# Combinatorial niche spider

## What this pack lets workers do

A collection of nouns and verbs for minting combinatorial multi-domain search cells (crossing
domain facets with intents, angles, technology stacks, 16 industry verticals, platforms,
cross-domain hybrids and injected phrases), advancing non-repeating per-cell page cursors (`1..5`),
expanding a persistent breadth-first spider frontier (`depth 2..8` across authors, forks and
outbound README links), refreshing longest-unchecked entries to surface star-surge `movers` and
`HTTP 404 gone` rot, scoring candidates on 8 separate `0-100` axes (`relevance`, `popularity`,
`commonality`, `usefulness`, `value`, `freeness`, `activity`, `rarity`), retiring `< 5%` yield
noisy wave families and gating curated admissions on an independent reviewer (`distinct_reviewer`).

## Nouns

| Noun (task object) | What it holds |
| --- | --- |
| Guardrails | Forbid competing schedulers (`auto_enqueued=False`); attach negative false-positive guards (`-interview -leetcode -homework`) and retire `< 5%` yield families; forbid curator self-approval (`409`) |
| `spec.niche-spider-axes-and-gates` | 8 separate `0-100` evaluation axes, BFS depth unlock progression (`2..8`), refresh thresholds and yield cutoffs |
| `rules.cursor-spider-and-refresh` | Rotating 8-path query plan (`base_grid`, `license_free`, `new_repo_radar`, `star_band_middle`, `in_readme_deep`, `awesome_list`, `dataset_benchmark`, `active_unknowns`) and anti-stall synonym mutations |
| `tool.niche-spider` | Tested standard-library Python package in [code/](code/README.md), pinned by path, file count and digest |
| `template.niche-spider-receipt` | JSON Schema for minted cell count, cursor advancement, spider edges, refresh movers/gone, retired noisy families and reviewed admissions |
| Worked example | Five-domain synthetic sweep (`example.niche-spider-bundle`) and recomputed receipt (`example.niche-spider-receipt`) |

## Verbs

| Verb (task) | Who | What happens |
| --- | --- | --- |
| `mint-niche-cells-and-paths` | agent, no model | Cross domain seeds, stacks, verticals, hybrids and custom phrases into SHA-256-pinned search cells |
| `sweep-cells-and-spider-frontier` | agent, no model | Advance uncovered page cursors, traverse BFS edges, refresh movers/404s and emit inert Wave 1-3 follow-up proposals |
| `review-eight-axis-admissions` | agent, no model | Score 8 axes, retire `< 5%` noisy families and enforce `distinct_reviewer` before admitting open-licensed tools |

## How to use it

Run `make check` in [code/](code/README.md) to run all unit tests including page-cursor progression,
negative interview-prep filtering, anti-stall synonym mutations, refresh mover/404 detection and
worked-example recomputation.

## Limits

- Quarantined, unverified proposal until reviewed: this pack is not installed, imported, admitted or
  activated, and no worker has claimed or run these tasks through Tessera.
- Offline cell forging, BFS simulation and 8-axis scoring run deterministically without network calls
  or unauthenticated API rate-limit collisions.
- Automated 8-axis scores filter false positives and surface candidates; accountable workers and
  people still inspect code, licenses and documentation before relying on any discovered repository.
