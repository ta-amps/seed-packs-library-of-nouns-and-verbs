# film_surface_rules

Standard-library Python package for evaluating declarative film and surface rule nouns (`<`, `<=`, `>=`, `abs<=`, `in_range`, `empty`, `is_true`, `is_false`), blocking forbidden made-up/non-functional stamps, computing frosted-pill caption geometry and dual-channel cognitive load, rewriting dead repository URLs to pinned `/source/` mirror routes, and auditing `/llms.txt` against MCP `tools/list` parity.
