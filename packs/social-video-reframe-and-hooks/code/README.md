# social_reframe

Standard-library Python planner for reframing 16:9 technical demos into 9:16, 1:1, and 4:5 cutdowns
with deadband-stabilized crop trajectories, hook-beat scoring, safe-band caption reflow, and
claim-preservation gates.

## Commands

```bash
python3 -m social_reframe plan timeline_spec.json --aspect 9:16
make check
```
