# Scene and cognitive video QA code

Standard-library Python package pinned by the `scene-and-cognitive-video-qa` seed pack.
It evaluates multi-frame shot dwell and text-crossfade transitions, unmotivated Ken Burns
zoom or pan drift on static slides, on-screen reading speed and split-attention prose
conflicts against concurrent narration and captions, live desktop web-journey provenance,
and widescreen lower-band frosted-caption centering and clause-balanced wrapping.

Run `make check` to compile with warnings treated as errors and run every unit test,
including exact recomputation of the worked example in `../source.json`.
