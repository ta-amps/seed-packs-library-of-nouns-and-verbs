# ivf_pq_cascade

Standard-library Python 3.10+ implementation of Inverted File with Product Quantization (`IVF-PQ`), Asymmetric Distance Computation (`ADC`) lookup tables and exact top-`R` rerank cascade governed by `default_grid_spec.json`.

## Commands

```bash
make check
python3 -m ivf_pq_cascade --bundle BUNDLE.json
```
