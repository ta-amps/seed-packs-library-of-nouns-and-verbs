# Loops schedules and heuristics

## What this pack lets workers do

A collection of nouns and verbs for inert window-keyed schedule compilation, fragility half-life urgency ranking, AIMD claim pacing, UCB1 anti-stall bandit loops, seven-tier compute resource cascades and six advice-only swappable learners.

## Nouns

| Noun (task object) | What it holds |
| --- | --- |
| Guardrails | Keep Schedule Nouns inert (`auto_enqueued=False`) with zero off-window storage I/O; keep swappable learners `advice_only=True` and block contributor-restricted or leaking training traces |
| `spec.schedules-bandit-and-seven-tier-cascade` | `schedule:<id>:<window_iso>` idempotency format, fragility half-life urgency formula, AIMD pacing and `0_code_shim` through `6_frontier_escalate` tiers |
| `rules.six-swappable-learners` | Reference rules for phrasing uplift, searchability scent, matched shim uplift, decomposition breakeven, Bradley-Terry taste and rights-cleared manifests |
| `tool.loops-schedules` | Tested standard-library Python package in [code/](code/README.md), pinned by path, file count and digest |
| `template.loops-schedules-receipt` | JSON Schema for window idempotency, off-window I/O count, urgency rank, AIMD concurrency, UCB1 arm, compute tiers and 6 learner verdicts |
| Worked example | Schedule, urgency, AIMD, bandit, compute and learner bundle (`example.loops-schedules-bundle`) and recomputed receipt (`example.loops-schedules-receipt`) |

## Verbs

| Verb (task) | Who | What happens |
| --- | --- | --- |
| `compile-inert-schedule-and-aimd-pacing` | agent, no model | Derive window-keyed `idempotency_key`s with zero off-window I/O, rank fragility half-life urgency and step AIMD claim concurrency |
| `step-bandit-anti-stall-and-compute-cascade` | agent, no model | Select UCB1 + empirical-Bayes arms with tombstone suppression and plateau mutation, and pick the lowest-cost valid compute tier |
| `evaluate-swappable-learner-advisors` | agent, no model | Run all six `advice_only=True` swappable learners and verify zero `task_family_id` overlap across rights-cleared splits |

## How to use it

Run `make check` in [code/](code/README.md) to execute unit tests covering `ZeroHardcodedValuesAstGate`, inert schedule compilation, `systemd --user` templates, fragility urgency, AIMD pacing, UCB1 anti-stall mutation, 7-tier compute cascades, all six swappable learners and worked-example receipt recomputation.

## Limits

- Quarantined, unverified proposal until reviewed: this pack is not installed, imported, admitted or activated, and no worker has claimed or run these tasks through a work-engine.
- Schedule compilation and `systemd --user` template rendering produce inert text and never register timers or start background processes.
- Swappable learners return `advice_only=True` recommendations; deterministic baselines remain authoritative whenever advice is disabled or rejected.
